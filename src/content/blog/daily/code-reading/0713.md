## 1. Java - 방어적 복사와 얕은 불변성

### 배경

외부에서 전달받은 상품 목록을 주문 객체가 보관한다. List.copyOf()로 리스트 자체의 변경을 막았지만, 리스트 안의 객체까지 불변인지 살펴보자.

```java
public final class Order {

    private final List<OrderItem> items;

    public Order(List<OrderItem> items) {
        if (items == null || items.isEmpty()) {
            throw new IllegalArgumentException("주문 상품이 필요합니다.");
        }

        this.items = List.copyOf(items);
    }

    public List<OrderItem> getItems() {
        return items;
    }

    public int totalPrice() {
        return items.stream()
                .mapToInt(OrderItem::totalPrice)
                .sum();
    }
}

public class OrderItem {

    private int price;
    private int quantity;

    public OrderItem(int price, int quantity) {
        this.price = price;
        this.quantity = quantity;
    }

    public void changeQuantity(int quantity) {
        this.quantity = quantity;
    }

    public int totalPrice() {
        return price * quantity;
    }
}
```
