## 1. 비공개 전환

이 글은 실제 로컬 네트워크에서 수집한 명령 출력과 장치 식별 정보가 포함되어 있어 비공개 초안으로 전환했다.

* Wi-Fi SSID, BSSID, MAC 주소와 장치 GUID를 삭제했다.
* 내부 IP 주소, 기본 게이트웨이, DHCP 서버와 DNS 서버 정보를 삭제했다.
* 실제 ARP 테이블과 네트워크 경로 추적 결과를 삭제했다.

공개 글에는 개인 환경에서 수집한 값을 사용하지 않고 문서용 예약 주소와 비식별화된 예시만 사용한다.
