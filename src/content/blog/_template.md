## 1. 들어가기 전

이 글을 작성하게 된 배경과 현재 글에서 답할 질문을 적는다.

## 2. 핵심 개념

개념의 정의, 등장 배경과 해결하려는 문제를 설명한다.

### 2.1 동작 원리

독자가 결과를 예측할 수 있도록 실행 흐름과 조건을 설명한다.

## 3. 코드 또는 적용 예제

코드에서 확인할 동작이나 문제를 먼저 설명한다.

```java
public class Example {
}
```

코드 뒤에는 실행 결과, 원인, 조건이나 설계상 의미를 설명한다. 코드에 이미 드러난 문법을 그대로 반복하지 않는다.

## 4. 중요한 조건과 예외

결론이나 코드 작성 방법에 영향을 주는 조건과 예외만 다룬다.
